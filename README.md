# Bulls & cows
**Gameplay:** guess the number. You enter a number, after which the number of bulls and cows is recalculated:
**-Cows** - the number of digits that are in both your number and the number you are guessing.
**-Bulls** - the number of digits that stand in the same place. Example: guessed 12054, your number is 12345. Bulls - 2 (1 and 2), cows - 2 (4 and 5). P.S. interface in Russian
